# ضيّ: صفحة هبوط لشركة طاقة شمسية

نموذج تصميمي لعلامة تجارية افتراضية. الصفحة مكتوبة بـ HTML وCSS وJavaScript عادي، ولا تحتاج أي build ولا مكتبات خارجية (باستثناء خط Google: Readex Pro).

## هيكل الملفات
```
index.html            المحتوى والأقسام
assets/css/style.css  التصميم (الألوان والخطوط في المتغيرات أعلى الملف)
assets/js/main.js     القائمة، والحركات، ودورة اليوم في الواجهة، والتبويبات، والحاسبة، ونموذج الطلب
```

## الأقسام
1. **الواجهة:** عنوان ووصف وزر طلب معاينة، وجنبهم رسمة SVG متحركة لبيت عليه ألواح. الشمس تتحرك من الشروق للغروب، والإنتاج والطاقة تتحسب لحظيًا.
2. **كيف تعمل:** المكونات الثلاثة، وتبويبات لأنواع الأنظمة (متصل بالشبكة / هجين / منفصل). التبويبات ممكن تتحرك بينها بالأسهم.
3. **الحاسبة:** تحسب حجم النظام وعدد الألواح والمساحة والإنتاج السنوي من الاستهلاك الشهري.
4. **الاستخدامات، وخطوات التركيب، والأسئلة الشائعة.**
5. **التواصل:** نموذج يتأكد من البيانات، ويبعت الطلب على واتساب، ومعاه نتيجة الحاسبة.

## تخصيص سريع
- **رقم واتساب:** `WHATSAPP_NUMBER` في `main.js`.
- **افتراضات الحاسبة:** `SUN_HOURS` و`PERF` و`PANEL_W` و`PANEL_M2` و`GRID_KG_PER_KWH` في `main.js`.
- **الألوان:** المتغيرات `--deep` و`--sun` و`--sand` في `style.css`.

## ملاحظات
- متجاوبة من ٣٢٠px، ومكتوبة للعربي (RTL) من البداية.
- الحركات بتقف لو المستخدم مفعّل "تقليل الحركة"، ورسمة الواجهة بتقف لما تخرج من الشاشة عشان توفّر البطارية.
- نتائج الحاسبة تقديرية، ومكتوب ده جوه الصفحة.
