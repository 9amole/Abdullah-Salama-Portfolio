# طبقة: صفحة هبوط لاستوديو طباعة ثلاثية الأبعاد

نموذج تصميمي لعلامة تجارية افتراضية. الصفحة مكتوبة بـ HTML وCSS وJavaScript عادي، ولا تحتاج أي build ولا مكتبات خارجية (باستثناء خطوط Google).

## هيكل الملفات
```
index.html            المحتوى والأقسام
assets/css/style.css  التصميم (المتغيرات في أعلى الملف: الألوان والخطوط والمسافات)
assets/js/main.js     القائمة، والحركات عند التمرير، ورسمة الطابعة، ونموذج الطلب
```

## تخصيص سريع
- **الألوان:** عدّل المتغيرات `--accent` و`--ink` و`--paper` في أول `style.css`.
- **رقم واتساب:** ضع الرقم في `WHATSAPP_NUMBER` داخل `main.js` (الصيغة الدولية بدون + مثل `2010XXXXXXXX`).
- **المحتوى:** كل قسم في `index.html` له `id` واضح (`service`، `work`، `steps`، `faq`، `contact`).

## مميزات تقنية
- تصميم متجاوب من ٣٢٠px حتى الشاشات الكبيرة، ومكتوب من البداية للعربية (RTL).
- حركات خفيفة تعتمد على `IntersectionObserver`، وتتوقف تلقائيًا لمن فعّل خيار "تقليل الحركة" في جهازه.
- رسمة الطابعة كلها SVG، فلا توجد صور ثقيلة، ووزن الصفحة كلها حوالي ٤٥ كيلوبايت قبل الخطوط.
- يمكن التنقل في الصفحة بالكيبورد، والأزرار عليها `aria-labels`، ويوجد رابط "تخطَّ إلى المحتوى".
- نموذج الطلب يتحقق من البيانات، ثم يجهّز رسالة واتساب جاهزة للإرسال، بدون الحاجة إلى Backend.
